Plug the Katana:GO into this computer or phone with a USB-C data cable

Then press Connect and allow MIDI access when the browser asks. Use Chrome or Edge (Web MIDI with SysEx).

Changes go to the amp's current tone straight away. They are not saved into a preset slot.
