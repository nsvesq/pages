MuraECHO

Tape Echo & Spring Reverb

A valve-driven tape echo into a spring tank, voiced for mid-fifties blues: short slapback, a bit of dirt, tape wobble and a boingy reverb. Built as a VST3 plugin and a standalone app.

Signal path

Input→ Valve drive→ Tape echo→ Spring tank→ Tone→ Output

Controls

KnobRangeWhat it does
Drive0–100 %Asymmetric soft clip, 2× oversampled. Grit rather than fuzz.
Time40–800 msSmoothed, so sweeping it pitch-bends like real tape. 90–140 ms is slapback.
Repeats0–110 %Feedback. Past 100 % it self-oscillates into saturation instead of blowing up.
Echo0–100 %How loud the repeats sit under the dry signal.
Age0–100 %The vintage knob: wobble depth, how fast repeats darken, and tape hiss.
Reverb0–100 %Spring tank mix.
Dwell0–100 %How long and how dark the spring rings.
Tone0–100 %Output low-pass, 1.5–15 kHz.
Output−24 to +12 dBMake-up gain.

Save your own settings from the preset bar. They're stored as small XML files, so they're easy to back up or share.

How it works

  • The echo's tone shaping sits inside the feedback loop (a low head bump, plus filters that close down with Age), so each repeat comes back darker and thinner than the last, like real tape.
  • The spring is 8 cascaded all-pass filters for the "boing", feeding 3 damped comb filters, band-limited to 140 Hz–4.2 kHz like a real tank.
  • Tested offline at 48 kHz: even at full Repeats with every knob maxed, it self-oscillates but stays bounded, with no NaNs.
